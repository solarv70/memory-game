# Memory Game

Memory Game is a card matching game created as part of the RS School course.

## Features

- 4x4 game board
- 8 pairs / 16 cards
- Shuffled cards
- Card matching
- Moves counter
- Matched pairs counter
- New Game
- Victory modal
- Leaderboard
- LocalStorage for best results
- Responsive layout

## How to Play

1. Open two cards.
2. Matching cards stay open.
3. Non-matching cards close after a short delay.
4. Match all 8 pairs to win.
5. Try to finish using as few moves as possible.

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

The application interface is generated dynamically with JavaScript using `document.createElement()`.

## Run Locally

1. Clone the repository:

   `git clone https://github.com/solarv70/memory-game.git`

2. Open the project folder.
3. Open `index.html` with Live Server or another local development server.
